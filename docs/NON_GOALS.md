# Non-Goals

This repository is not a:

- universal financial data model;
- execution protocol;
- settlement protocol;
- accounting ledger;
- custody standard;
- blockchain transaction standard;
- compliance decision engine;
- Sharia rule system; or
- real provider connector library.

It also does not provide production exchange or custodian connectors, broker integrations, customer mappings, reconciliation heuristics, private APIs, credentials, production infrastructure or production security configuration.

The schemas normalize only the initial event families listed in the repository instructions. They do not determine whether lending, staking, yield, funding, balance or transfer activity is permitted, prohibited, compliant or non-compliant.
