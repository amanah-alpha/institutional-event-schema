# Security

## Scope

This repository contains public schemas, synthetic fixtures, documentation and local validation tools. It contains no production connectors, credentials, customer data, private APIs, production infrastructure or production security configuration.

Schema validity is not evidence that a source record is true, complete, authentic or safe. Consumers must apply their own trust, access-control, transport, storage and resource-limit policies.

Content digests in these schemas provide change detection relative to a referenced representation. They are not signatures, attestations or proof of external truth.

## Reporting a vulnerability

Report suspected vulnerabilities through the private security-reporting mechanism configured for this public repository. Do not include live credentials, customer records or other sensitive production material in an issue, fixture or proof of concept.

Reports should identify the affected file and release, describe the impact, and provide the smallest synthetic reproduction practical. Public schema-design questions that do not expose a vulnerability may use the ordinary public issue process.

## Supported versions

Until a stable 1.0.0 release, security corrections are applied to the latest published schema release only.
