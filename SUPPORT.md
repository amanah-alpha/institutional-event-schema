# Support

1. **Docs first:** `schema/*.schema.json` are self-describing contracts;
   `tests/` are the executable specification.
2. **Questions:** GitHub Issue with the `question` label.
3. **Bugs:** bug template + minimal payload.
4. **Security:** Private Vulnerability Reporting only.

## Out of scope

Sharia rulings, regulatory advice, production engine support (see
amanah-alpha boundaries). Triage is weekly; security first.
